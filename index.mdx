## Como funciona

```
Usuário WhatsApp → Meta → Coexy → Webhook → Seu servidor
                                ↑
                     meta-proxy ← Seu servidor
```

- **Receber:** quando uma mensagem chega, o Coexy entrega via POST para sua URL de webhook
- **Enviar:** seu servidor chama o meta-proxy com o `channel_token` e o Coexy encaminha para a Meta

## Pré-requisitos

- Uma conta no [Coexy](https://coexy.com.br)
- Uma API Key (gerada em **Configurações → API Keys**)
- Um endpoint HTTPS público para receber eventos (ou uma Supabase Edge Function)
