## Como funciona

```
Usuário WhatsApp → Meta → Cartsapp → Webhook → Seu servidor
```

Quando uma mensagem chega em um dos seus canais, o Cartsapp envia um evento via POST para a URL configurada no seu webhook. Seu servidor recebe, verifica a assinatura HMAC, e processa.

## Pré-requisitos

- Uma conta no [Cartsapp](https://cartsapp.com.br)
- Uma API Key (gerada em **Configurações → API Keys**)
- Um servidor com endpoint HTTPS público para receber eventos
