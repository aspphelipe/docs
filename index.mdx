## Como funciona

```
Usuário WhatsApp → Meta → Coexy → Webhook → Seu servidor
```

Quando uma mensagem chega em um dos seus canais, o Coexy envia um evento via POST para a URL configurada no seu webhook. Seu servidor recebe, verifica a assinatura HMAC, e processa.

## Pré-requisitos

- Uma conta no [Coexy](https://coexy.com.br)
- Uma API Key (gerada em **Configurações → API Keys**)
- Um servidor com endpoint HTTPS público para receber eventos
