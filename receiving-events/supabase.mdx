Se você usa **Lovable, Bolt, Cursor ou qualquer plataforma com Supabase**, este é o caminho correto. O Deno runtime suporta a Web Crypto API nativamente — sem dependências extras para HMAC.

<Warning>
**Nunca chame a API do Coexy diretamente do frontend React.** Credenciais no código React ficam visíveis no browser para qualquer usuário. Use sempre Edge Functions como intermediárias — as credenciais ficam nos secrets do servidor.
</Warning>

## Migration

Crie a tabela para persistir as mensagens recebidas:

```sql
-- supabase/migrations/001_messages.sql
create table if not exists messages (
  id          uuid primary key default gen_random_uuid(),
  wamid       text not null,
  channel_id  text not null,           -- phone_number_id do canal (metadata.phone_number_id)
  from_number text not null,
  type        text not null default 'text',
  body        text,
  status      text,                    -- último status (sent, delivered, read, failed)
  received_at timestamptz not null default now(),
  created_at  timestamptz not null default now(),
  constraint messages_wamid_unique unique (wamid)
);

alter table messages enable row level security;
```

Execute:

```bash
supabase db push
```

## Edge Function

```typescript
// supabase/functions/coexy-webhook/index.ts
/// <reference types="https://esm.sh/@supabase/functions-js/src/edge-runtime.d.ts" />
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2'

// Cliente criado uma vez, reutilizado entre invocações
const supabase = createClient(
  Deno.env.get('SUPABASE_URL')!,
  Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!,
)

const encoder = new TextEncoder()

async function verifySignature(
  body: string,
  signatureHeader: string,
  secret: string,
): Promise<boolean> {
  if (!signatureHeader.startsWith('sha256=')) return false

  const expectedHex = signatureHeader.slice(7)
  if (expectedHex.length % 2 !== 0) return false

  const key = await crypto.subtle.importKey(
    'raw',
    encoder.encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['verify'],
  )

  const expectedBytes = new Uint8Array(expectedHex.length / 2)
  for (let i = 0; i < expectedHex.length; i += 2) {
    expectedBytes[i / 2] = parseInt(expectedHex.slice(i, i + 2), 16)
  }

  return crypto.subtle.verify('HMAC', key, expectedBytes, encoder.encode(body))
}

async function processEvent(value: Record<string, unknown>): Promise<void> {
  // O body é o "value" nativo da Meta: { messaging_product, metadata, contacts, messages, statuses }
  const metadata = value.metadata as Record<string, string> | undefined
  const phoneNumberId = metadata?.phone_number_id ?? ''

  // Mensagens recebidas
  for (const msg of (value.messages as unknown[]) ?? []) {
    const m = msg as Record<string, unknown>
    await supabase.from('messages').upsert({
      wamid:       m.id,
      channel_id:  phoneNumberId,
      from_number: m.from,
      type:        m.type ?? 'text',
      body:        (m.text as Record<string, string> | undefined)?.body ?? null,
      received_at: new Date(Number(m.timestamp) * 1000).toISOString(),
    }, { onConflict: 'wamid', ignoreDuplicates: true })
  }

  // Status de mensagens enviadas
  for (const st of (value.statuses as unknown[]) ?? []) {
    const s = st as Record<string, unknown>
    await supabase.from('messages').update({ status: s.status }).eq('wamid', s.id)
  }
}

Deno.serve(async (req: Request) => {
  if (req.method !== 'POST') {
    return new Response('Method Not Allowed', { status: 405 })
  }

  const body = await req.text()
  const signature = req.headers.get('x-coexy-signature') ?? ''
  const secret = Deno.env.get('COEXY_HMAC_SECRET') ?? ''

  const valid = await verifySignature(body, signature, secret)
  if (!valid) {
    return new Response('Unauthorized', { status: 401 })
  }

  const event = JSON.parse(body) as Record<string, unknown>

  // Responde 200 ANTES de processar — EdgeRuntime.waitUntil garante que
  // o processamento conclua mesmo após o retorno da Response
  if (typeof EdgeRuntime !== 'undefined') {
    EdgeRuntime.waitUntil(processEvent(event).catch(console.error))
  } else {
    processEvent(event).catch(console.error)
  }

  return new Response('OK', { status: 200 })
})
```

## Variáveis de ambiente

Configure os secrets no projeto Supabase:

```bash
supabase secrets set COEXY_HMAC_SECRET='seu-hmac-secret'
```

<Note>
`SUPABASE_URL` e `SUPABASE_SERVICE_ROLE_KEY` são injetados automaticamente em Edge Functions — não é necessário configurar.
</Note>

## Deploy

```bash
supabase functions deploy coexy-webhook
```

A URL da função é:

```
https://<project-ref>.supabase.co/functions/v1/coexy-webhook
```

Use essa URL ao criar o webhook no Coexy:

```bash
curl -X POST https://api.coexy.com.br/functions/v1/api/webhooks \
  -H "x-api-key: crt_pk_sua-chave" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Meu receptor",
    "url": "https://<project-ref>.supabase.co/functions/v1/coexy-webhook",
    "events": ["messages"]
  }'
```

<Warning>
Salve o `hmac_secret` retornado e configure via `supabase secrets set` antes de testar.
</Warning>
